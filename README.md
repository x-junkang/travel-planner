# 旅行规划助手 · travel-planner

一个面向 Codex 的个人旅行规划 Skill。国内旅行优先，兼容境外旅行；以携程查询为主，结合官方来源核对，把目的地和大致出行时间转化为可执行的攻略。

## 能做什么

- 集中补齐出发地、日期弹性、人数、预算、住宿要求和兴趣等关键信息。
- 正式查价前检查携程登录，未登录时先引导用户完成；登录后重新确认查询条件。
- 比较往返及城市间交通，整理班次、时刻、价格、接驳和关键条件。
- 推荐住宿区域和具体酒店，核对入住日期、房型、人数、房数及费用。
- 境外首选航班和各落脚点首选酒店再尝试一至两个国际平台或官网，比较同条件总价与差异。
- 按地理位置编排每日路线，考虑开放时间、预约、移动、用餐和休息。
- 为主要景点补充实用介绍卡片，说明看点、推荐理由、玩法、停留时间、体力及天气要求。
- 汇总全员与人均预算，提供预订行动清单和来源链接。
- 交付聊天摘要及保存在当前工作区 `outputs/` 的完整 Markdown 攻略。

## 安装

在终端执行，安装到个人 Codex 技能目录：

```sh
mkdir -p ~/.codex/skills
git clone https://github.com/x-junkang/travel-planner.git ~/.codex/skills/travel-planner
```

如果目标目录已存在，请先检查并保留其中的本地修改，再决定如何合并；不要直接覆盖。已通过此仓库克隆安装且没有本地修改时，可以使用 `git -C ~/.codex/skills/travel-planner pull --ff-only` 更新。

## 使用

在 Codex 对话中显式调用 `$travel-planner`，也可直接提出与技能描述匹配的旅行规划需求。例如：

```text
请使用 $travel-planner，帮我规划 2027 年 4 月从上海出发的云南旅行，
大约 7 天，日期可调整。两名成人，全程总预算 12000 元，
喜欢自然风景和当地美食，节奏轻松，酒店交通方便。
请先补问必要信息，再查询交通和具体酒店，生成完整攻略。
```

这是使用示例，日期、人数与预算应替换为你的实际需求。修改已有攻略时，说明变化，技能会同步检查交通、住宿、每日安排及预算。

## 查询环境与边界

技能本身是一组可复用的工作说明，不包含机票或酒店库存接口。查询依赖 Codex 当前可用的联网工具；页面交互复用 `browser:control-in-app-browser` 技能，请在使用环境中提供相应能力。

浏览器选择遵循 Browser 技能及用户的明确指示，本技能不固定为电脑默认浏览器。携程作为主平台，在正式查价前检查登录：已登录直接继续，未登录则打开入口并等待用户完成，期间可继续研究景点和路线；用户明确不登录时，再按其选择使用公开报价或跳过该平台。补充平台仅在查询受限时请求登录。登录和验证码均由用户在所选浏览器内完成，技能不保存账号凭据，不包含下单、付款、取消订单或持续价格监控功能。

境外酒店可参考 Booking.com、Agoda 或酒店官网；航班可用 Skyscanner 发现选项，再核对实际售票方。同条件比价考虑房型或票价产品、人数、税费、行李、早餐和退改政策，保留原币及统一币种参考价；特殊优惠需核对适用资格。某平台无房不代表酒店全部售罄，无法比价会注明缺口，不承诺全网最低价。

报价分为“页面查询报价”“参考估算”和“待核实”，并记录条件、来源及查询时间。平台起价或搜索摘要不会被当作指定日期的可订报价；多人交通优先按实际人数查询，单人价乘人数仅作明确标注的推算。查询不到时保留缺口，实际预订时的价格与库存以平台为准。
